# tipos-laudo

Catálogo dos 10 tipos de laudo (templates) e sua estrutura: seções, campos por
seção (seleção única/múltipla/texto livre/tabela), opções possíveis e texto
automático associado a cada marcação.

Tabelas relacionadas no schema: `tipos_laudo`, `secoes`, `campos_secao`.

Modelos já mapeados: Curatela, Previdenciário, Trabalhista (ver CLAUDE.md da raiz).
Os outros 7 ainda serão adicionados aqui conforme a cliente enviar — por isso o
schema é genérico e template-driven, não deve exigir remodelagem.
